# matriq-atom-lab
A Demonstration of Neutral-Atom Quantum Computing Platform

## Interactive learning lab

An interactive learning explorer for neutral-atom quantum computing, designed for readers developing a practical physics background.

Explore Rb (and Yb) atom supply, trapping and cooling, optical tweezer arrays, single-qubit control, Rydberg-mediated gates, measurement, and physical/ logical qubits. This application includes a glossary and primary-source reading notes.

## Run locally

No build or package installation is required.

## GitHub Pages

All asset URLs are relative, so this works beneath a repository path.

## Teaching-model boundaries

This is an educational model based on public experiments. Source papers and assumptions are linked inside the application.
