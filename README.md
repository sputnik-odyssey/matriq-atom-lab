# matriq-atom-lab
Neutral-Atom Platform Demonstration

## Interactive learning lab

An interactive learning explorer for neutral-atom quantum computing, designed for readers developing a practical physics background.

Explore Rb and Yb atom supply, trapping and cooling, optical tweezer arrays, single-qubit control, Rydberg-mediated gates, measurement, and physical versus logical qubits. The application includes a glossary and primary-source reading notes.

## Run locally

Serve this directory with any static web server, for example `python3 -m http.server 8000`, and open `http://localhost:8000`. No build or package installation is required.

## GitHub Pages

Publish the `main` branch from the repository root (`/`). The `.nojekyll` file tells GitHub Pages to serve the static files directly. All asset URLs are relative, so this works beneath a repository path.

## Teaching-model boundaries

This is an educational model based on public experiments, not a specification of MatriQ hardware. Its two-level state controls and measurement are idealized; the blockade and error-correction demonstrations are labeled teaching models. Source papers and assumptions are linked inside the application.

## Visual identity

MatriQ logo artwork and the standard RGB palette follow the supplied visual identity reference. Interface and diagram text uses Times New Roman when available, with a serif fallback. MatriQ names and marks remain with their respective owner.
